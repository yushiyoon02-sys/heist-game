Slime Heist: Gem Snatch — a top-down heist game. A pink thief slime sneaks
through three guarded museum rooms: dodge the guard slimes' flashlight beams
and the sweeping cameras, stand at the pedestal to pocket the gem, then slip
out the getaway door. Being seen fills the alarm meter — sneak with Shift to
fill it slower, break line of sight to let it drain. Decoy coins (Q) and
smoke puffs (E) help, at a score cost; a ghost bonus rewards never being
spotted. Keyboard and mouse, anime cel-shaded slimes, no sound. Runs offline
from static files in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Node 22.18 or later,
no dependencies, no network.
